12 / SCIENTIFIC METHODOLOGY
Temperature gradient
The horizontal temperature gradient is computed using spherical-coordinate finite differences.

Wind components
Meteorological wind direction is converted to eastward and northward wind components.

Kinematic frontogenesis
The horizontal deformation contribution to the rate of change of the horizontal temperature gradient is calculated.

Interpretation
Positive values indicate strengthening of the horizontal thermal gradient. Negative values indicate weakening.

This is a single-pressure-level kinematic diagnostic, not the complete three-dimensional atmospheric frontogenesis budget.
